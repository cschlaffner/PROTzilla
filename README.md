# PROTzilla

This is a work-in-progress version. 
Please refer to the current PROTzilla at https://github.com/cschlaffner/PROTzilla2

Currently, only .sh installation script is supported. Should install all dependencies used for new frontend and backend from PROTzilla2.
Dependencies are managed via
- backend: requirements.txt
- frontend: pnpm 

Github workflows should work as expected.

### Install scripts
#### .sh
- installs all dependencies 
- expects pnpm, node.js to be installed
- opens frontend index.html built by pnpm via backend-configured port http://127.0.0.1:8000/
