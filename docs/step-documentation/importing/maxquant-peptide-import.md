# MaxQuant Peptide Import

Imports peptide-level data from a MaxQuant `peptides.txt` file. PROTzilla extracts peptide sequences, protein identifiers, sample-specific intensities, and PEP values for use in peptide-based analyses. For details about the file format, see the [MaxQuant peptide table documentation](https://cox-labs.github.io/coxdocs/output_tables.html#3-peptide-table).
