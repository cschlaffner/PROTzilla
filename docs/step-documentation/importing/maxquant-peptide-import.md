# MaxQuant Peptide Import

Imports peptide-level data from a MaxQuant `peptides.txt` file. PROTzilla extracts peptide sequences, protein identifiers, sample-specific intensities, and PEP values for use in peptide-based analyses. The meaning of PEP is described under [Filter Peptides: PEP Threshold](../data-preprocessing/filter-peptides-pep-threshold.md). For details about the file format, see the [MaxQuant peptide table documentation](https://cox-labs.github.io/coxdocs/output_tables.html#3-peptide-table).
